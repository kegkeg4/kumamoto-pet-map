# くまもとペット捜索マップ — 令和8年(2026年)熊本地震 災害対応版

迷子ペット(犬・猫)の「さがしています」と「保護しています」を1つの地図で繋ぐ、完全無料・非営利のサービス。7/28熊本地震(最大震度7)対応。

## 今すぐデプロイする手順(最短15分)
1. GitHubに新規リポジトリ作成 → このフォルダをpush
2. Render → New → Web Service → リポジトリ選択
   - Runtime: Python 3 / Build Command: 空 / Start Command: `python server.py`
   - **Instance: Starter($7/月)を強く推奨**(無料枠は15分でスリープ=緊急時に致命的。また再起動でデータ消失)
   - **Disks → Add Disk**: Mount Path `/opt/render/project/src/data`、1GB(投稿データと写真の永続化。必須)
3. 環境変数 `ANTHROPIC_API_KEY` を設定(SNS/チラシ文面のAI生成。未設定でも定型文で動作)
4. `https://xxx.onrender.com/health` で `{"ok": true}` を確認
5. 独自ドメイン(例: pet-kumamoto.jp 等)を割当て → SNSで告知

## 主な機能
- **2つの掲示板**: 🔍さがしています(迷子) / 🏠保護しています(保護者・避難所・病院が投稿)
- **犬・猫・その他対応**: 猫は行動特性が違うため、捜索半径モデル(半径50m〜最大500m)と捜索のコツ(夜間・物陰・追いかけない)を専用化
- **相互マッチング候補**: 迷子ページに同種の最新保護情報、保護ページに同種の迷子情報を自動表示(2016年熊本地震では保護2,499匹中返還411匹 — 「保護されているのに繋がらない」問題への対策)
- 目撃情報マップ / 捜索済みエリアの塗りつぶし共有(150mメッシュ・時間減衰)
- チラシA4印刷+QR / X・Instagram用文面(AI生成、フォールバック付き)
- 管理トークン方式(登録者のみ再会報告・編集可)
- 災害情報ページ: 熊本市動物愛護センター(096-380-2153)・県保健所・警察・マイクロチップ、車中泊の熱中症注意、余震下の捜索安全注意
- スパム対策: レートリミット / ハニーポット / 座標検証 / 画像マジックバイト検証 / 通報3件で自動非表示

## 運用の注意
- 完全無料・非営利を明示(フッター記載済み)。災害対応での収益化はしない
- 電話番号(096-380-2153)は県公式ページ記載のものだが、公開前に一度発信確認を推奨
- 通報された投稿はflags>=3で自動非表示。誤非表示の解除はDB直接操作(P2で管理画面)

## 愛護センター掲載情報の自動取込(city_sync.py)
- 熊本市動物愛護センターの「保護しています」「飼い主さんが探しています」計6一覧を巡回し、事実情報(種別・日付・場所)+元記事リンクのみを取込。写真は既定OFF(センター許諾後に --with-photos)
- 市サイトから記事が消えたら自動クローズ(返還・掲載終了とみなす)
- 位置は区レベルのおおよそ表示(詳細ページに明記)。負荷対策で2秒間隔・UA明示
- 実行: `python3 city_sync.py --dry-run` で確認 → cron等で 災害時2〜3時間おき / 平時1日1回
- ⚠ 運用前にセンターへ電話(096-380-2153)し、出典明記での転載可否を確認すること(掲載挨拶と同じ電話でOK)
